### 1. 产品概述

- **产品名称**：Idea Wall 创意墙
- **产品愿景**：打造一个激发创新、促进协作的创意管理平台
- **产品目标**：
  - 为团队提供一个收集和管理idea的统一平台
  - 通过积分激励机制鼓励创新
  - 建立标准化的idea评审流程
  - 加速优质idea向实际解决方案的转化

### 2. 角色定义

- **普通用户**：
  - 可以浏览、搜索、点赞和评论idea
  - 可以获取和使用积分
  - 可以接收相关通知
  - 可以创建和管理自己的idea
  - 可以提交idea进入评审流程
  - 可以跟踪idea的评审状态

- **评审组成员**：
  - 具有普通用户的所有权限
  - 负责评审分配到的idea，并给出评审结果

- **孵化器成员**：
  - 具有评审组成员的所有权限
  - 负责对通过初审的idea进行深入评估，并给出孵化评估结果

- **管理员**：
  - 具有系统最高权限
  - 管理用户角色和权限
  - 查看系统日志

### 3. idea生命周期

1. **创建阶段**
   - 用户提交idea
   - 完善idea详情
   - 收集初步反馈

2. **评审阶段**
   - 提交评审申请
   - 评审组审核
   - 评审结果通知

3. **孵化阶段**
   - 提交孵化申请 (Lean canvas / POC)
   - 孵化评估
   - 孵化结果通知

4. **实施阶段**
   - 解决方案开发
   - 效果验证
   - 总结复盘

### 4. 主要功能

- **核心功能**：

  1. **Idea管理**
     - 提交idea：用户可以提交新的idea，包含标题、描述、类别、标签等
     - idea详情：展示idea的详细信息、当前状态、评论、点赞数等
     - idea编辑：创建者可以编辑和更新idea内容
     - idea删除：创建者可以删除自己的idea
     - idea状态追踪：显示idea在生命周期中的当前阶段

  2. **搜索和发现**
     - 全文搜索：支持按关键词搜索idea
     - 高级筛选：按类别、状态等多维度筛选
     - 排序功能：支持按热度、时间等方式排序
     - 推荐系统：基于用户兴趣和行为推荐相关idea

  3. **互动功能**
     - 评论系统：用户可以对idea发表评论
     - 点赞功能：用户可以对idea和评论点赞
     - @提醒：在评论中可以@其他用户

  4. **积分系统**
     - 积分规则：
       - 提交idea获得积分
       - 收到点赞获得积分
       - idea被评审通过获得额外积分
       - 孵化成功获得积分
     - 积分商城：可以用积分兑换奖品
     - 积分排行榜：展示用户积分排名

  5. **评审流程**
     - 提交评审：idea创建者可以提交idea进入评审
     - 评审表单：标准化的idea评审表单
     - 评审流程：
       - idea会议评审
       - POC验证
       - 孵化评估
     - 评审反馈：评审结果和意见反馈

  6. **通知系统**
     - 站内通知：
       - idea收到新评论
       - 评论收到回复
       - 收到点赞
       - idea状态更新
       - 评审结果通知
     - 邮件通知：重要事件的邮件提醒
     - 通知设置：用户可自定义通知方式和频率

  7. **个人中心**
     - 我的idea：展示用户创建的所有idea
     - 收件箱：显示待处理的任务和通知
     - 积分明细：查看积分获取和使用记录
     - 个人设置：通知设置、邮件订阅等

   8. **系统日志**
     - 记录所有用户操作的日志，将日志记录到Logs Collection中，日志只能记录，不能修改或删除
     - 支持日志查看和搜索，可选择同一条数据记录的日志进行比较

### 5. 技术栈

- **前端技术栈**：Angular + PrimeNG，实现在 idea-wall-ui
- **后端技术栈**：Python FastAPI，实现在 idea-wall-api
- **数据库**：MongoDB
- **登录验证**：OAuth，responseType = token。使用JwksValidationHandler作为tokenValidationHandler，使用JwtHelperService解析token。
